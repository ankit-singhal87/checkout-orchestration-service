# ADR 0005: SCAYLE Inspired, Not Cloned

## Status

Accepted

## Decision

Use SCAYLE public documentation as inspiration for checkout concepts, not as a source to copy API specs, schemas, tenant conventions, or UI behavior.

## Consequences

- The demo can discuss SCAYLE-like architecture while remaining original.
- The OpenAPI spec will be simplified and project-specific.
- Endpoint naming may borrow broad concepts like checkout state, but not SCAYLE's exact API surface.
- Proprietary behavior and UI details are out of scope.
