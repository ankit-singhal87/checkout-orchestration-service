# Documentation

Documentation is split by purpose.

- [../wiki](../wiki/README.md) - human-readable project knowledge base:
  status, architecture, runbooks, review docs, and current-state context.
- [automation](automation/README.md) - compact execution control plane:
  constraints, commands, workflow, validation rules, and orchestration guidance.
- [api](api) - stable API specifications.
- [prd](prd/checkout-mvp-prd.md) - product requirements and acceptance criteria.
- [design](design/checkout-mvp-architecture-design.md) - technical design and
  architecture details.
- [adr](adr/README.md) - architecture decision records.
- [plans](plans/checkout-mvp-work-plan.md) - workflow plans and phase plans.
- [contracts](contracts) - implementation contracts and behavior boundaries.
- [standards](standards) - implementation standards.
- `ui-spec` is reserved for future Codex Workflow artifacts.

Use the root [README](../README.md) for the public landing page.
