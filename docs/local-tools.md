# Local Tools

## Required For Phase 0

- Git
- Docker
- Docker Compose

## Required Later

- PHP
- Composer
- Go
- Node.js and npm, if frontend asset compilation is needed
- Terraform
- `kubectl`
- `kind` or `k3d`
- `protoc`

## Optional

- `glab` for GitLab convenience
- `gh` for GitHub mirror checks
- Xdebug for PHP debugging
- Go debugger tooling after Go workers are introduced

Run:

```bash
sh scripts/dev/check-tools.sh
```
