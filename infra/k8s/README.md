# Kubernetes

Kubernetes manifests or Helm-style overlays will live here for local Kubernetes first and optional EKS later.

## Phase 1 Scope

- Keep deployment assets as placeholders until the Laravel app and local Docker Compose path exist.
- Prefer local Kubernetes validation with `kind` or `k3d` before any EKS work.

## Deploy Rule

AWS deployment is optional and manual. GitHub Actions must not deploy.
